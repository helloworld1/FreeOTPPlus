FreeOTP+ lägger till ett andra säkerhetslager för dina onlinekonton.
Det fungerar genom att generera engångslösenord (OTP) på dina mobila enheter som används tillsammans med ditt vanliga lösenord för att göra din inloggning nästintill omöjlig att kapa.
Dessa lösenord kan genereras även när telefonen är i flygplansläge.
Token kan enkelt läggas till genom att skanna en QR-kod eller genom att ange tokenkonfigurationen manuellt.
Detta kallas tvåfaktorsautentisering (2FA).

FreeOTP fungerar med många av de populära onlinetjänster du redan använder, inklusive Google, Facebook, Evernote, GitHub och många fler!
FreeOTP fungerar även för intern företagssäkerhet om de standardiserade protokollen <a href="https://en.wikipedia.org/wiki/Time-based_one-time_password">TOTP</a> eller <a href="https://en.wikipedia.org/wiki/HMAC-based_one-time_password_algorithm">HOTP</a> används.
Detta inkluderar utmärkta företagslösningar som <a href="https://www.freeipa.org/">FreeIPA</a>.

<b>Funktioner:</b>
<ul>
<li>Skanna QR-koder eller ange tokenkonfigurationer manuellt.</li>
<li>Exportera och importera tokens (FreeOTP+ JSON eller Key URI, i klartext eller krypterade, med val att lägga till eller ersätta), importera säkerhetskopior från FreeOTP XML och Aegis Authenticator JSON samt anpassade tokenbilder (ZIP) via Google Drive eller andra dokumentleverantörer.</li>
<li>Material Design 3-gränssnitt med system-, ljust och mörkt tema.</li>
<li>Sök efter tokens, tilldela flera kategorier med kategorifilter och sortera efter konto, utfärdare eller dra-och-släpp.</li>
<li>Visa och redigera tokendetaljer, dela via QR-kod eller kopiera token-URI:er.</li>
<li>Tre autentiseringslägen: Inget, Vid appstart (biometri / PIN-kod) och Krypterad token (AES-256-GCM-krypterade hemliga tokennycklar som låses upp med biometri eller manuell nyckel).</li>
<li>Inbyggda offline-ikoner för över 450 tjänster med sökbar ikonväljare samt stöd för egna bilder och SVG-ikoner.</li>
<li>100 % offline utan internetbehörighet, med skärmbildsskydd och automatisk rensning av känsligt urklippsinnehåll.</li>
</ul>

FreeOTP Plus är en förgrening (fork) av FreeOTP.
