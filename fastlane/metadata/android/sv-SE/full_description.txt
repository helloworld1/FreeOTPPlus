FreeOTP+ lägger till ett andra säkerhetslager för dina onlinekonton.
Det fungerar genom att generera engångslösenord (OTP) på dina mobila enheter som används tillsammans med ditt vanliga lösenord för att göra din inloggning nästintill omöjlig att kapa.
Dessa lösenord kan genereras även när telefonen är i flygplansläge.
Token kan enkelt läggas till genom att skanna en QR-kod eller genom att ange tokenkonfigurationen manuellt.
Detta kallas tvåfaktorsautentisering (2FA).

FreeOTP fungerar med många av de populära onlinetjänster du redan använder, inklusive Google, Facebook, Evernote, GitHub och många fler!
FreeOTP fungerar även för intern företagssäkerhet om de standardiserade protokollen <a href="https://en.wikipedia.org/wiki/Time-based_one-time_password">TOTP</a> eller <a href="https://en.wikipedia.org/wiki/HMAC-based_one-time_password_algorithm">HOTP</a> används.
Detta inkluderar utmärkta företagslösningar som <a href="https://www.freeipa.org/">FreeIPA</a>.

<b>Funktioner:</b>
<ul>
<li>Skanna QR-kod.</li>
<li>Exportera och importera inställningar till Google Drive eller andra dokumentleverantörer.</li>
<li>Material Design med stöd för mörkt tema.</li>
<li>Sökfält för att söka efter token.</li>
<li>Visa tokendetaljer.</li>
<li>Alternativ för att kräva biometrisk autentisering / PIN-kod vid start av appen.</li>
<li>Heuristikbaserade offline-ikoner för token från över 250 webbplatser.</li>
<li>Många inställningar för att anpassa appens funktioner.</li>
</ul>

FreeOTP Plus är en förgrening (fork) av FreeOTP.
