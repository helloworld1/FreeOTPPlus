FreeOTP+ adds a second layer of security for your online accounts.
This works by generating one-time passwords (OTP) on your mobile devices which can be used in conjunction with your normal password to make your login nearly impossible to hack.
These passwords can be generated even when your phone is in airplane mode.
Tokens can be added easily by scanning a QR-code or by manually entering the token configuration.
This is called two-factor authentication (2FA).

FreeOTP works with many of the great online services you already use, including Google, Facebook, Evernote, GitHub and many more!
FreeOTP also may work for your private corporate security if they implement the standardized <a href="https://en.wikipedia.org/wiki/Time-based_one-time_password">TOTP</a> or <a href="https://en.wikipedia.org/wiki/HMAC-based_one-time_password_algorithm">HOTP</a> protocols.
This includes great enterprise solutions like <a href="https://www.freeipa.org/">FreeIPA</a>.

<b>Features:</b>
<ul>
<li>Scan QR codes or enter token configurations manually.</li>
<li>Export and import tokens (FreeOTP+ JSON or Key URI, plaintext or encrypted, with Append or Replace All options), import backups from original FreeOTP XML and Aegis Authenticator JSON, and back up custom token images (ZIP) via Google Drive or other document providers.</li>
<li>Material Design 3 interface with System, Light, and Dark themes.</li>
<li>Search tokens, assign multiple categories with category filters, and sort by account, issuer, or drag-and-drop order.</li>
<li>View and edit token details (with HOTP counter badges and protected secret reveal), share via QR code, or copy token URIs.</li>
<li>Three authentication modes: None, App launch (Biometric / PIN), and Token encrypted (AES-256-GCM encrypted token secrets unlocked via biometric or manual key).</li>
<li>Built-in offline icons for 450+ services with a searchable icon picker, plus custom image and SVG icon support.</li>
<li>100% offline with no internet permission, screenshot protection, and automatic sensitive clipboard clearing.</li>
</ul>

FreeOTP Plus is a fork of FreeOTP.
