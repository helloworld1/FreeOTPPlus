O FreeOTP+ adiciona uma segunda camada de segurança para suas contas online.
Ele funciona gerando senhas de uso único (OTP) no seu dispositivo móvel, usadas em conjunto com sua senha normal para tornar seu login praticamente impossível de ser invadido.
Essas senhas podem ser geradas mesmo quando o telefone está em modo avião.
Os tokens podem ser adicionados facilmente escaneando um código QR ou inserindo manualmente a configuração do token.
Isso é chamado de autenticação de dois fatores (2FA).

O FreeOTP funciona com muitos dos ótimos serviços online que você já usa, incluindo Google, Facebook, Evernote, GitHub e muitos outros!
O FreeOTP também pode ser usado na segurança corporativa privada caso implementem os protocolos padronizados <a href="https://en.wikipedia.org/wiki/Time-based_one-time_password">TOTP</a> ou <a href="https://en.wikipedia.org/wiki/HMAC-based_one-time_password_algorithm">HOTP</a>.
Isso inclui excelentes soluções corporativas como o <a href="https://www.freeipa.org/">FreeIPA</a>.

<b>Recursos:</b>
<ul>
<li>Escaneamento de código QR.</li>
<li>Exportação e importação de configurações para o Google Drive ou outros provedores de documentos.</li>
<li>Material Design com suporte ao tema escuro.</li>
<li>Barra de pesquisa para buscar tokens.</li>
<li>Visualização dos detalhes do token.</li>
<li>Opção para exigir autenticação biométrica / PIN ao abrir o aplicativo.</li>
<li>Ícones offline baseados em heurística para tokens de mais de 250 sites.</li>
<li>Diversas configurações para personalizar as funcionalidades do aplicativo.</li>
</ul>

O FreeOTP Plus é um fork do FreeOTP.
