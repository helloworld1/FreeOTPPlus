FreeOTP+ додає другий рівень захисту для ваших онлайн-облікових записів.
Застосунок генерує на ваших мобільних пристроях одноразові паролі (OTP), які використовуються разом зі звичайним паролем, роблячи злам входу майже неможливим.
Ці паролі можна генерувати навіть тоді, коли телефон перебуває в режимі польоту.
Ключі можна легко додати, відсканувавши QR-код або ввівши налаштування ключа вручну.
Це називається двофакторною автентифікацією (2FA).

FreeOTP працює з багатьма популярними онлайн-сервісами, якими ви вже користуєтеся, зокрема Google, Facebook, Evernote, GitHub та багатьма іншими!
FreeOTP також підходить для корпоративної безпеки, якщо використовується стандартизований протокол <a href="https://en.wikipedia.org/wiki/Time-based_one-time_password">TOTP</a> або <a href="https://en.wikipedia.org/wiki/HMAC-based_one-time_password_algorithm">HOTP</a>.
Сюди входять такі корпоративні рішення, як <a href="https://www.freeipa.org/">FreeIPA</a>.

<b>Можливості:</b>
<ul>
<li>Сканування QR-коду.</li>
<li>Експорт та імпорт налаштувань через Google Диск або інші постачальники документів.</li>
<li>Material Design із підтримкою темної теми.</li>
<li>Рядок пошуку для пошуку ключів.</li>
<li>Перегляд деталей ключа.</li>
<li>Можливість вимагати біометричну автентифікацію / PIN-код під час запуску застосунку.</li>
<li>Офлайн-піктограми на основі евристики для ключів понад 250 вебсайтів.</li>
<li>Багато налаштувань для персоналізації функціональності застосунку.</li>
</ul>

FreeOTP Plus є форком FreeOTP.
