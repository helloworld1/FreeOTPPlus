FreeOTP+ ajoute une deuxième couche de sécurité à vos comptes en ligne.
L'application génère sur vos appareils mobiles des mots de passe à usage unique (OTP) utilisables en complément de votre mot de passe habituel pour rendre vos connexions quasiment impossibles à pirater.
Ces mots de passe peuvent être générés même lorsque votre téléphone est en mode avion.
Les jetons s'ajoutent facilement en scannant un code QR ou en saisissant manuellement leur configuration.
C'est ce qu'on appelle l'authentification à deux facteurs (A2F / 2FA).

FreeOTP fonctionne avec de nombreux services en ligne que vous utilisez déjà, notamment Google, Facebook, Evernote, GitHub et bien d'autres !
FreeOTP peut également être utilisé pour la sécurité de votre entreprise si celle-ci implémente les protocoles standardisés <a href="https://en.wikipedia.org/wiki/Time-based_one-time_password">TOTP</a> ou <a href="https://en.wikipedia.org/wiki/HMAC-based_one-time_password_algorithm">HOTP</a>.
Cela inclut d'excellentes solutions d'entreprise telles que <a href="https://www.freeipa.org/">FreeIPA</a>.

<b>Fonctionnalités :</b>
<ul>
<li>Scan de code QR.</li>
<li>Exportation et importation des paramètres vers Google Drive ou d'autres fournisseurs de documents.</li>
<li>Interface Material Design avec prise en charge du thème sombre.</li>
<li>Barre de recherche pour trouver rapidement un jeton.</li>
<li>Affichage des détails du jeton.</li>
<li>Option permettant d'exiger une authentification biométrique / code PIN au lancement de l'application.</li>
<li>Icônes hors ligne basées sur l'heuristique pour les jetons de plus de 250 sites web.</li>
<li>Nombreux paramètres pour personnaliser le fonctionnement de l'application.</li>
</ul>

FreeOTP Plus est un fork de FreeOTP.
