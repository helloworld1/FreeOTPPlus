FreeOTP+ 為您的線上帳號提供第二層安全防護。
它會在行動裝置上產生一次性密碼 (OTP)，並與您平時使用的密碼搭配使用，讓帳號登入幾乎無法被破解。
即使手機處於飛航模式，也能正常產生這些密碼。
只需掃描 QR Code 或手動輸入權杖設定，即可輕鬆新增權杖。
這稱為兩步驟驗證 (2FA)。

FreeOTP 支援許多您經常使用的線上服務，包括 Google、Facebook、Evernote、GitHub 等！
若您的企業內部安全系統實作了標準化的 <a href="https://en.wikipedia.org/wiki/Time-based_one-time_password">TOTP</a> 或 <a href="https://en.wikipedia.org/wiki/HMAC-based_one-time_password_algorithm">HOTP</a> 協定，FreeOTP 同樣能搭配運作。
其中包含 <a href="https://www.freeipa.org/">FreeIPA</a> 等優秀的企業級解決方案。

<b>功能特色：</b>
<ul>
<li>掃描 QR Code 或手動輸入權杖設定。</li>
<li>透過 Google 雲端硬碟或其他文件提供者匯出與匯入權杖（FreeOTP+ JSON 或 Key URI，支援純文字或加密，可選擇附加或取代全部）、匯入原版 FreeOTP XML 與 Aegis Authenticator JSON 備份，以及備份自訂權杖圖示（ZIP）。</li>
<li>支援跟隨系統、淺色與深色主題的 Material Design 3 介面。</li>
<li>支援搜尋權杖、指派多個分類並依分類篩選，以及依帳號、發行者或拖曳順序排序。</li>
<li>檢視與編輯權杖詳細資訊、透過 QR Code 分享或複製權杖 URI。</li>
<li>三種身分驗證模式：無、啟動應用程式時（生物辨識 / PIN）及權杖加密（以 AES-256-GCM 加密權杖密鑰，並透過生物辨識或手動金鑰解鎖）。</li>
<li>內建超過 450 個服務的離線圖示並提供可搜尋的圖示選擇器，同時支援自訂圖片與 SVG 圖示。</li>
<li>無需網路權限即可 100% 離線運作，具備防螢幕截圖保護與敏感剪貼簿內容自動清除功能。</li>
</ul>

FreeOTP Plus 是衍生自 FreeOTP 的分支版本。
